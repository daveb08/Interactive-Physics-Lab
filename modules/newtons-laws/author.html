Placeholders: keep text in sync with these settings

Type a placeholder such as {v0} or {a} in any statement, card, block or feedback. Students see the current value, so changing a setting updates the text everywhere. Use plain numbers where you want a fixed value (for example, the wrong number in a trap card). A plotted answer left blank also uses the simulation’s value.

4 · Step 2: solution steps and blocks

Each step has one correct block and any number of wrong blocks. Wrong blocks need misconception feedback. Optionally, give a wrong block the acceleration or v₀ it implies so the ghost shows that motion, and give blocks a numerical answer to plot on the graphs.
